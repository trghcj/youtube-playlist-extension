# Security Policy

## Supported Versions

We actively maintain and provide security updates for the current version of the extension on the `main` branch and the Chrome Web Store.

| Version | Supported          |
| ------- | ------------------ |
| 1.0.x   | :white_check_mark: |
| < 1.0   | :x:                |

---

## Reporting a Vulnerability

User privacy and extension security are taken very seriously. This extension runs locally in the user's browser, requires zero external server communication, and collects no personal information.

If you believe you have discovered a security vulnerability in this extension:

1. **Do not create a public issue** on GitHub.
2. Please report the vulnerability privately by either:
   - Opening a **[Private Security Advisory](https://github.com/trghcj/youtube-playlist-extension/security/advisories/new)** directly through GitHub.
   - Contacting the project maintainer via GitHub profile [@trghcj](https://github.com/trghcj).

### What to Include in Your Report

To help us investigate and resolve the issue quickly, please provide:
- A clear description of the potential vulnerability and its impact.
- Exact steps to reproduce the issue (or a minimal proof-of-concept).
- Your browser version (Chrome, Brave, Edge, etc.) and OS.

### Response & Timeline

- **Initial Acknowledgment**: Within 48 hours of receipt.
- **Investigation**: We will reproduce, verify the issue, and determine appropriate mitigation.
- **Fix & Disclosure**: Once resolved, an updated version will be committed to `main` and published to the Chrome Web Store, after which public disclosure can proceed.
